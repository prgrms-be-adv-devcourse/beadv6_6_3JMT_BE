## 등급 A — 런타임 설정값 (yml 수정 + 재기동이면 끝)

`@ConfigurationProperties`로 묶는다: `search.ranking.*`, `search.suggest.*`,
`search.pipeline.*`, `recommendation.*`

## 등급 B — 인덱스 매핑에 박히는 값 (변경 = products-v2 리인덱스 + alias 전환)

yml로 뺄 수 없다 — 색인된 데이터 자체의 모양이라 바꾸면 전부 재색인.
그래서 문서 1 §6의 alias 전환 절차를 미리 설계해뒀다.
